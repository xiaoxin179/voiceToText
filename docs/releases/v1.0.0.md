# Voice Studio v1.0.0 · Windows 独立客户端

## 下载与使用

下载 `VoiceStudio-1.0.0-windows-x64.zip`，完整解压，然后双击 `VoiceToText/VoiceToText.exe`。
无需安装 Python、激活 Conda 或运行 BAT，不会常驻黑色控制台窗口。
这是包含 EXE 和运行库的便携程序包，请保留整个目录。
`SHA256SUMS.txt` 可用于校验下载完整性。GitHub 自动生成的 Source code 是源码，不是客户端。

## 运行条件

Windows 10/11 x64。模型未包含在程序包中，沿用当前用户的 Hugging Face 模型缓存；首次使用需按仓库 README 准备 tiny 和 medium 模型。
GPU 推理仍需要兼容的 NVIDIA 驱动，CPU 模式可在客户端选择。
模型准备、源码运行和构建方法见 [README](https://github.com/xiaoxin179/voiceToText#readme)。
